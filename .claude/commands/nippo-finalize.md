# 日報を完成させる

本日の日報（~/work/nippo/$(date +%Y-%m-%d).md）を完成させます。
本日分の日報がない場合は前日の日報を完成させます。

## 実行内容:

1. **進捗状況の集計**
   - 作業ログから本日の活動を分析
   - 達成した項目と未達成の項目を整理

2. **各セクションの補完**
   - 空欄になっているセクションを埋める
   - 作業ログから重要なポイントを抽出

3. Git commit & push
   - 日報が完成したら、`git commit -m "$(date +%Y-%m-%d)"` で Git にコミット
   - `git push` でリモートリポジトリに反映
